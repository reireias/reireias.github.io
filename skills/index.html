03 / Details

経験と実績

01横断的な課題発見と改善の仕組み化

SRE、セキュリティ、AI活用、アーキテクチャの各領域で、顕在化した問題を解決するだけでなく、多数のリポジトリ、サービス、チームを俯瞰して潜在的な課題を見つけることを得意としています。

メトリクスやログ、クラウドコスト、インシデント、開発フロー、現場からのフィードバックを組み合わせ、影響範囲と緊急度を整理して優先順位を判断します。

発見した課題は、各リポジトリの事情を確認し、必要に応じてオーナーや関係者と相談・調整したうえで、対象となるリポジトリへ導入して回ります。個別対応で終わらせず、コード化・標準化・自動化・教育を通じて継続的に改善できる仕組みとして展開します。

横断的な調査や実装にはAIエージェントも活用します。複数リポジトリへの変更を効率的かつ安全に進めるだけでなく、得られた知見や手順をSkillやプラグインとして標準化し、次の課題発見と改善に再利用できる形で残します。

  • 複数サービスに共通する信頼性・運用負荷・コストのボトルネックの発見
  • AWSアカウントやリポジトリを横断したセキュリティリスクの可視化
  • AIエージェント導入時のガバナンス、可観測性、開発体験に関する課題の整理
  • AIエージェントによる横断実装と、Skill・プラグインによる手順の標準化
  • 技術課題と事業・組織への影響を踏まえたロードマップと改善施策の策定・調整
02システムアーキテクト

可用性、コスト、拡張性、運用などを考慮したシステム全体のアーキテクチャ設計を行うことが得意です。

プラットフォームはAWS、GCP、自社データセンター等を利用してきました。OSはLinux系を一通り構築に使ったことがあります。

最近はAWSのマネージドサービスを活用し極力運用負荷が少なく、過度に複雑すぎない、負債になりにくいシステム設計を心がけて設計しています。

過去に業務で構築した経験のある構成は次の通りです。

  • ELB + EC2 + RDS
  • ECS(Fargate)を利用したコンテナベースのアプリケーション
  • API Gateway + LambdaやCloudFront + Lambda Edge等のサーバーレス構成
  • SQS + SNS + Lambdaを利用したキューチェーン型システム
03Infrastructure as Codeの実現

Infrastructure as Codeによる利点と恩恵を考慮した上で、管理/変更/レビュー/運用のしやすいInfrastructure as Codeな世界を実現することができます。

ツールとしてはTerraformを利用することが多いですが、CloudFormationによる実装経験もあります。

Terraform CloudでのCI/CD自動化を経て、現在はコストと開発体験の観点からGitHub Actions上でのplan/apply自動実行に全面移行して運用しています。AWS/GCPに加え、GitHub自体の管理などにも活用しています。

04社内の全AWSアカウント横断でのセキュリティ対策

"AWS Well-Architected"やベストプラクティスに則ったセキュリティ対策の実施が可能です。

特に複数のAWSアカウントを横断したOrganizationやCloudTrail、SecurityHubを用いた一元的なセキュリティ対策と検知の仕組みの構築を推奨しております。

セキュリティKPIの策定と月次レビュー体制の確立、セキュリティロードマップの策定など、組織のセキュリティを継続的に改善する仕組みづくりも担当しています。

ログ改ざん耐性の確保やDB監査ログの取得など、実践的なセキュリティ対策の構築経験もあります。

サプライチェーン攻撃に対しては、依存バージョンの固定・SASTの導入・CI/CDのハードニングなど、予防的な仕組みを複数リポジトリへ横展開しています。

05ゲームデーの開催

実際のセキュリティインシデントさながらの攻撃シナリオを用意し、テスト環境に攻撃を行いそれをチームで調査・対応する訓練を過去に何度か開催してきました。

AWSとセキュリティの知識を駆使してより実践的なゲームデーを開催することが可能です。

06クラウドコストの最適化

AWSを中心としたクラウドコストの分析と削減を得意としています。

単なる削減に留まらず、開発体験や運用効率の向上を同時に実現する施策を心がけています。

過去に業務で行ってきた主な取り組みは次の通りです。

  • Terraform CloudからGitHub Actionsへの全面移行によるCI/CDコストの大幅削減
  • ARM(Graviton)化やS3ストレージクラス移行など、全サービス横断でのコスト削減施策の提案・推進
  • コスト削減ノウハウのドキュメント化による、チーム全体での継続的な最適化体制の構築
07パフォーマンスチューニング

Webアプリケーションエンジニア時代から負荷試験や性能改善等を業務で担当してきました。

APMやモニタリングツールやプロファイラーを利用した本番環境やCI上のボトルネックの特定と、WebアプリケーションやRDBMSやLinux OSの知識を活用しパフォーマンス改善を行うことができます。

08可観測性(Observability)基盤の構築

メトリクス・ログ・トレースを組み合わせた可観測性基盤の設計・構築ができます。

Amazon Managed Prometheus / GrafanaやOpenTelemetry(ADOT)などのマネージドサービスを活用し、コスト帰属・異常検知・セキュリティ監査の土台となる基盤を本番構築した経験があります。

09CI/CDパイプラインの構築

CIに関しては、GitHub Actions/CircleCI/Travis CI等の使用経験があり、Linux + Dockerの知識も合わせて適切な設定を行うことができます。

CDに関しては主にAWSのCodeシリーズを利用しての構築が得意です。

以下に業務で実際に行ってきたものを列挙します。

  • まれに落ちるテストや時間のかかるテストによるCI詰まりなどの分析/修正
  • Blue/Greenデプロイメントやロールバック手順の確立
  • AWS SSMパラメータストアやKMS等を利用した秘匿情報の適切な管理
  • Dockerイメージビルドの高速化
  • CI/CDパイプラインにおける適切なキャッシュ設定
10運用系ツールの作成と運用

もともとサービスのフロントエンド/バックエンドの開発が長く、現在でも社内のリソース状況に応じてアプリケーションの実装を担当したり、趣味での実装の多くがWebアプリケーション開発なので、実はインフラと同等以上にアプリケーション開発のスキルもあったりします。

これを活かし、省リソース(要はワンオペ)での管理機能等の小さいサービスのインフラとアプリケーション両方の開発や、日々の運用で利用するような夜間停止やSlack連携などの軽いLambdaアプリケーション等、開発時の便利系スクリプト等の実装を担当することが多くありました。

11データ分析/可視化基盤の構築

ビッグデータ解析とまではいかないですが、それなりに多量のデータを格納し、分析/可視化するための基盤の構築も何度か経験があります。

データ量やリアルタイム性、分析する対象に応じて適切なデータ格納方法やデータパイプラインを構築し、ビジネスメンバーの興味関心に応じたダッシュボード作成等を実践してきました。

個人的にはエンジニアサイドでSQL等のクエリを実行できるBI環境を提供し、ビジネスサイドでKPIや施策に応じたクエリを日々作成していくスタイルが理想です。

入門〜上級までニーズに応じて様ざなま形式で開催し、社内の技術力の底上げに貢献しています。

特に好評な勉強会をいくつか掲載します。

13Webアプリケーション開発のリーディング

過去にBtoBやBtoCを含め、6プロダクトほどサービス開発を経験してきました。

セキュリティや可用性、性能等の非機能要件を考慮した開発や、メンバーのスキルや学習コスト/メンテナンスコストを考慮した技術選択等を実践できます。

認証や非同期処理、大規模システムの結合ビルドの調整等、比較的難易度の高い部分を担当することが多いです。

最近は若手層への教育を行いながら開発リーダーを務めることが多いです。(スクラムマスター、プロダクトオーナーではないので、開発外部との交渉/調整等は専門外ですが)

また、IPAの資格で応用情報技術者、セキュリティスペシャリスト、データベーススペシャリストを保有しています。

1年以上業務で利用経験のある言語: Ruby, Java, C#, js, ts

同フレームワーク: Ruby on Rails, Spring, Vue.js

15開発環境の構築や改善

Webアプリケーションと本番環境のインフラ構成に加え、DockerやLinux等の知識があるため、開発環境まわりの構築や改善を実施してきました。

これらの知識を組み合わせることで、本番環境をなるべく再現しつつも起動が高速で扱いやすいローカルの開発環境を構築したり、クレデンシャル/API

Tokenのセキュリティや職能/職種に合わせた権限設定を考慮したリポジトリや成果物管理の仕組み等、開発環境とその周辺を構築してきました。

技術的にこれらを構築するだけでなく、開発フローやブランチ戦略の考案/改善といったことも得意だったりします。

16AIを活用した開発と仕組みづくり

AIエージェントを活用した開発（AI駆動開発）に日常的に取り組んでいます。

社内規約を組み込んだClaude Codeのプラグインや、Datadog/Notion/AWS Cost ExplorerなどのMCP統合、リポジトリ横断作業のためのマルチエージェント制御など、AIを活用した開発基盤の整備を進めてきました。

多数のリポジトリに共通する課題の調査、変更対象の選定、実装、検証にもAIエージェントを活用しています。作業を速めるだけでなく、リポジトリごとの差異を踏まえて安全に展開し、その手順をSkillとして再利用可能にすることを重視しています。

AIによって変化し続ける開発の在り方に対して、SRE / セキュリティの知見を活かしたガードレールやポリシー・仕組みづくりに関心があり、Claude Enterpriseの全社導入におけるセキュリティ設計なども担当しています。

チーム全体でAIエージェントが安全かつ効果的に動作する環境を整備していくことを志向しています。
